tema oscuro · primario

Positivo = tinte 15 % + borde sólido + ✓ en círculo relleno. Atención = triángulo relleno. Error = × en círculo relleno. Inactivo = glifo tachado en gris. Interactivo / fijado = acento halo. El color nunca va solo.Positive = 15 % tint + solid border + ✓ in a filled circle. Attention = filled triangle. Error = × in a filled circle. Inactive = slashed glyph in grey. Interactive / pinned = halo accent. Color never goes alone.

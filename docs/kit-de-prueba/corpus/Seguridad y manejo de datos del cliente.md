# Dónde viven los datos
Todo el trabajo ocurre en equipos del consultor, cifrados en reposo. No se suben extractos a servicios de terceros.

# Retención
Los extractos se borran a los treinta días del cierre. El cliente recibe constancia escrita.

# Confidencialidad y acceso a sistemas
El acceso se pide por escrito, se limita a lectura y se revoca el día del cierre.

# Certificaciones
No hay certificación ISO vigente. Las prácticas siguen la norma sin estar auditadas por un tercero.

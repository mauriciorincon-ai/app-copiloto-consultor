# Las cuatro etapas
El marco recorre inventario, calidad, gobierno y uso. Ninguna etapa empieza sin que la anterior tenga un responsable con nombre.

# Inventario
Se listan las fuentes, quién las produce y con qué frecuencia cambian. Sin este paso, la calidad se mide sobre datos que nadie reclama.

# Calidad
Se acuerdan cinco reglas por fuente y se miden semanalmente. La meta no es cero errores: es saber cuántos hay.

# Gobierno
Define quién responde por cada fuente y cada cuánto se revisa. Es la etapa que más se salta y la que más cuesta recuperar.

# Uso
Un tablero sin decisión asociada es un tablero muerto. Cada indicador nace con la decisión que va a mover.
